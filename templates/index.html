📖 Help

Workflow

1. Select your network interface from the top bar dropdown, then click Lock. Restart the app to change.

2. Click Deep Scan — 3-pass ARP + ICMP sweep discovers all hosts.

3. Click one or more hosts in the Target panel to select them. Ctrl+click for multi-select. Selected targets appear as chips in the attack form.

4. Select an attack type, configure parameters, then click Launch Attack.

5. Click Stop Attack to end. PCAP is saved to pcap_analysis/ automatically.

Button Rules

• Launch Attack — greyed until: interface locked + at least one target selected + no scan running.

• Stop Attack — only active while an attack is running.

• Interface Lock — greyed once locked. Restart to change.

Multi-Target Attacks

When multiple targets are selected, the attack runs against all selected IPs in sequence. Each IP gets its own thread where supported.

PCAP Files

Saved to ./pcap_analysis/attackname_YYYYMMDD_HHMMSS.pcap. View the PCAP list from the top bar button. Run: wireshark -r filename.pcap -Y "filter"
